# الم الشتاء | Winter Realm ❄️

لعبة تعليمية وترفيهية شتوية باللغة العربية، مصممة لتعمل مباشرة على الهاتف والكمبيوتر.

## المميزات
- واجهة عربية كاملة باتجاه RTL وثيم زجاجي شتوي متجاوب.
- لعبة تركيب الحروف لمفردات الملابس والشتاء.
- لعبة صيد الثلج التفاعلية.
- لعبة ذاكرة لمطابقة الكلمات والرموز.
- مؤثرات ثلج وعاصفة، وأصوات مولّدة عبر Web Audio دون ملفات خارجية.
- حفظ أفضل النقاط تلقائياً في `localStorage`.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع لنشره كرابط عام.
